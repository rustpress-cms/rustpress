WordPress, without PHP.

RustPress is a replacement for WordPress written in Rust. Point it at the database and wp-content/ folder of an existing site with a block theme, and it serves the same pages, feeds and REST answers, checked byte for byte against a real WordPress.

Get started Download Source on GitHub 
docker run -p 3000:3000 -v /path/to/wordpress:/var/www/html \
  -e RUSTPRESS_DATABASE_URL=mysql://user:pass@db:3306/wordpress \
  ghcr.io/rustpress-cms/rustpress

How it works

No migration, no export, no new data format. RustPress works with what a WordPress site already has, and answers requests the way WordPress would.

Same database

RustPress reads the usual wp_* tables in MySQL or MariaDB as they are. You can switch back to WordPress at any time.

Same files

Block themes, uploads, translations and block.json files come from your wp-content/ and the WordPress files on disk.

Same output

Same HTML, same feeds, same REST responses, same redirects. Core and themes are ported to Rust; there is no PHP interpreter.

What it does

The website, the REST API and the administration area, as one small binary.

Website

Pages, posts, archives, search and 404 with the site's block theme, including responsive images and galleries. Twenty Seventeen is rebuilt natively.

Feeds and SEO basics

Permalinks of every kind, canonical redirects, RSS2 and Atom feeds, comment feeds, sitemaps and robots.txt.

REST API

wp/v2 for posts, pages, media, categories, tags, users and comments, for reading and writing.

Administration

wp-admin with sign-in, the block editor, media, comments, users, settings, privacy tools and export.

Installer

A WordPress-style installer that can download and verify the WordPress files by itself.

Every language

Every language WordPress has a language pack for, including right-to-left languages. E-mail goes out over SMTP.

Checked against a real WordPress

Plugins as native modules

PHP plugins do not run. Important plugins are rebuilt in Rust instead and take over while the plugin is active in WordPress, with the same settings, the same output and the same behaviour. The plugin's files simply stay in wp-content/plugins.

Will it run my site?

Ask RustPress before it takes over: rustpress check reads the active theme and plugins with the site's configuration, says which of them run, and changes nothing.

$ rustpress check
[ok  ] Theme twentytwentyfive: block theme, runs as it is
[ok  ] Plugin wordpress-seo/wp-seo.php 28.8: native module
[no  ] Plugin elementor/elementor.php 3.30.0: PHP plugin without a native module; RustPress ignores it

Runs

Block themes, Twenty Seventeen, the six plugins above, page caches and WP Mail SMTP (not needed), every site language.

Not yet

Other classic PHP themes, page builders such as Elementor or Divi, WooCommerce, any other PHP plugin, Multisite, the Customizer.

Missing a plugin?

Open a port request, or port it yourself with the step-by-step guide.

Install

Every release carries ready-made builds. The Linux binaries are linked statically, so one file runs on every distribution.

  • Linux x86_64, aarch64, armv7, armv6, i686
  • .deb · .rpm · .apk
  • macOS Intel and Apple Silicon
  • Windows x64, x86, ARM64
  • FreeBSD
  • Container: amd64, arm64, arm/v7, arm/v6, 386

Server

# rustpress.toml
database_url = "mysql://wordpress:secret@127.0.0.1:3306/wordpress"
wp_root      = "/var/www/html"
listen       = "127.0.0.1:3000"
allow_writes = true   # sign-in, comments, wp-admin
RUSTPRESS_CONFIG=rustpress.toml rustpress

Without allow_writes the database session is read-only and the administration area stays closed. TLS is left to a reverse proxy.

Docker Compose

cp .env.example .env   # set the password and address
docker compose up -d   # RustPress and MariaDB

Then open the site and follow the installer, or point WORDPRESS_DIR at an existing WordPress folder and import its database dump.

Shared hosting (CGI)

On hosts that only offer Apache with CGI, put the static binary into cgi-bin/. RustPress detects CGI mode by itself, reads the database settings from wp-config.php and takes over the site through .htaccess. On an empty webspace the installer downloads the WordPress files from wordpress.org, checksum-verified.

From source

git clone https://github.com/rustpress-cms/rustpress
cd rustpress
cargo run --release -p rustpress-server

All settings can also be given as RUSTPRESS_* environment variables; see the README.

RustPress is experimental. It is tested against WordPress 7.1.4 and runs a real site in production, but expect rough edges. Keep a backup of your database and the WordPress files before pointing it at a live site.

Classic PHP themes other than Twenty Seventeen and PHP plugins without a native module do not run.
